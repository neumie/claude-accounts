Variant C: Command palette

Keyboard-first. The popup opens with focus in a 28px filter field and the keyboard cursor already on the most recently used other account, so ↵ alone flips back and forth between the two accounts Jakub uses most. Number keys 1–9 switch straight away while the filter is empty (numbers stay fixed, they never reorder). Typing filters accounts and actions together. esc clears the filter, then closes. The active account is marked with an accent check plus an "Active" chip and gets no stripe. The only stripe is the keyboard cursor, so "where ↵ goes" and "what is active" never look the same. A "This tab" strip shows up only when the current tab is an artifact. It holds the Undo after an auto-switch, or the confirm in Ask mode. A one-line status bar at the bottom carries the auto-switch mode (Auto / Ask / Off) and the last auto-switch event. One filled-accent element at most per screen, and only where a decision is waiting.
