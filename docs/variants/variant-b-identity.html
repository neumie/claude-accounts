Variant B — Identity first

The popup opens on one question: who is Chrome signed in as right now. A large identity block (avatar, email as the only 17px title, orgs as plain text, live session line) owns the top. Below it, a compact "Switch to" list holds the other accounts as 36px single-line rows, each row being the switch button itself, with "Add account" as the last row. A "This tab" section closes the popup and explains the artifact in the active tab: its title and id, which account opens it, and the last auto-switch with Undo, or the confirm step in Ask mode. Section order never changes, so the eye always lands in the same place. Settings and remembered artifact mappings live one push away behind the header's settings button.
